# Desktop GUI Application

This directory contains the Tkinter Desktop Dashboard GUI for the Personal Finance Management System.

## How to Run

From the root project directory, run:

```bash
python gui/gui_app.py
```

## Features
- **Summary Cards**: Displays Total Income, Total Expenses, Net Savings, and Monthly Budget.
- **Add Transactions**: Input income or expense entries with amount validation.
- **Transaction Table**: Color-coded Treeview table for income (green) and expenses (red).
- **Delete Selected**: Multi-select and delete records.
